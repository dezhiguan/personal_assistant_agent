02 第一版的边界

先做这些

  • 纯文字聊天、生成状态、停止回复
  • 新建对话、最近对话、本机记录
  • Python 服务调用一个真实模型
  • 同一会话连续追问、失败提示与重试
  • LangSmith 记录调用与错误，方便排查

以后再逐步扩展

  • 文件上传与个人知识库
  • 联网检索、日历和第三方工具
  • 跨会话长期记忆与自动化任务
  • 多助理协作、账户和云端同步
