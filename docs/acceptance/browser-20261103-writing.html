修复内容

  1. 通用写作条件规范合并，原始消息保存；简单明确请求与短修正快速路由，复杂/否定/冲突语义仍交给路由模型，不把未理解句子静默裁剪。全新作文不继承旧的文件保存流程。
  2. 控制经持久队列，在模型/工具安全边界应用；在途过期候选先结算再丢弃，不进入交付/计划校验，不用取消重启模拟 Steering。
  3. 复用 Harness 压缩和归档：归档已结算写参数及失败长回执；execute 等输出也使用预算预览；最新用户要求保留，摘要索引不再被额外消息扰乱；严格计数比较采用相同当前要求。
  4. 原图累计预算不放宽。可安全恢复的上下文/传输错误保留 checkpoint 和草稿，提供“继续”；重复上下文失败有界停止并解释下一步。未知写入不自动恢复。
  5. 三类网络传输超时正确分类，避免 Requests 超时因继承 OSError 被误报为磁盘故障。预算/用量回调写回所属事件循环，维持同 Thread 单写入者。
  6. 作文目标篇幅、语言、完整结尾校验复用既有交付钩子；字数说明不再误判为没有结尾；短交付回执与作文正文分开计数，显式硬上限保持原样。拒绝稿全量归档，仅最近一稿参与改写，旧稿不反复堆入模型上下文；不是去掉全部草稿后让模型从头再写。Unicode wc -m 核验字符，避免拿 UTF-8 字节数或空格分词估算中文字数。
  7. 自然进度直接读取任务状态；区分接收要求与已应用要求；恢复待核对操作不再写成“正在调用”。会话目录、回执、聊天与成果从持久记录恢复并去重。
